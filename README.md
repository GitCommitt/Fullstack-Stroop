# README: Internationaal Software Development Project (Zweden)

## Projectomschrijving
Dit project is een resultaat van een zes maanden durende samenwerking tussen drie software developers uit Nederland en een school in Zweden. Het doel van het project was het ontwikkelen van een Website waarop informatie over de samenwerking en verschillende ontwikkelde games worden gepresenteerd.

Gedurende de looptijd van het project heeft er een internationale uitwisseling plaatsgevonden. Hierbij is er fysiek op locatie in Zweden samengewerkt om de development-fase te versnellen en de integratie tussen de verschillende onderdelen te realiseren.

## Tijdlijn en Werkwijze
Het project kende een totale looptijd van een half jaar en was onderverdeeld in de volgende fasen:

1. **Bezoek (Nederland):** Het project startte met een bezoek van de Zweedse studenten aan Nederland. Tijdens deze intensieve week zijn de basisconcepten vastgelegd, de rollen verdeeld en de technische vereisten opgesteld.
2. **Remote Development (Lange Online Periode):** Na de eerste fysieke ontmoeting volgde een uitgebreide online periode. Vanuit Nederland en Zweden is er remote samengewerkt aan de opzet van de website en de development van de eerste prototypes van de games.
3. **Bezoek (Zweden):** Het project werd afgerond met een tegenbezoek van een week aan Zweden. Deze week stond volledig in het teken van de hoofdontwikkeling, het samenvoegen van de codebases, uitgebreid testen en het live zetten van de uiteindelijke website.
